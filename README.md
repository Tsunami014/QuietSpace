# Quiet space
A quiet space on the web for relaxing in

## Running
To run the game you must host this folder, the easiest way to do so is via python (just run `python3 -m http.server`)

Then go to `.../test.html` for the test or just the plain url for the production version (must build first)

## Building
Run `build.sh` ensuring you have `minify` and `esbuild` installed and avaliable.
